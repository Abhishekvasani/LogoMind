# Trademark & Distinctiveness — Starter Set

> *Originality wins eyes; distinctiveness survives court. The spectrum from generic to fanciful is the real risk axis under every "is it different enough?" question.*

---

## RS-LIC-TM-001 — The Distinctiveness Spectrum

**Definition:** Legal strength of a mark rises with distance from what the words/symbols literally mean
**Generic (never registers):** The common name of the goods — "Coffee" for a café; a leaf for an eco brand's only device is functionally generic imagery
**Descriptive (weak, hard to register):** Describes a quality or feature — "Swift Delivery", a lightning bolt for a fast service
**Suggestive (registrable, common sweet spot):** Requires imagination to connect — "Netflix" suggests films; a keystone for reliability suggests without describing
**Arbitrary (strong):** Common word/symbol, unrelated goods — "Apple" for computers; an anchor for a software firm
**Fanciful (strongest):** Coined exclusively — "Kodak"; a wholly invented symbol form
**Design implication:** Symbol + wordmark TOGETHER can be distinctive even when each part is weak — the combination is the mark
**Best For:** Judge risk scoring; Create avoiding legally-dead directions

## RS-LIC-TM-002 — Common Refusal Grounds (Design-Relevant)

**Definition:** The practical reasons marks get refused, translated for designers
**Likelihood of confusion:** Too close to an existing mark in the same class — similar sight, sound, or meaning; dominance of similarities over differences decides it
**Merely descriptive:** The mark just names a feature (words) or literally depicts the product (symbols)
**Ornamental refusal:** A design used purely decoratively (all-over prints) doesn't function as a source identifier
**Deceptive misdescription:** Suggests a quality the goods don't have — a globe+wing for a purely domestic service invites trouble
**Best For:** Coach pitfalls; Judge "risk" field grounding

## RS-LIC-TM-003 — The Designer's Clearance Basics

**Definition:** What a designer can sanity-check before a lawyer bills hours
**Knockout search:** Search the exact name + near spellings in the relevant trademark class (and visually similar logos in that class) — free databases cover national registers
**Class awareness:** Rights are per class — "Meridian" in class 25 (apparel) does not block class 42 (software); the designer's brief should note the client's classes
**Visual neighbours:** For logo-led marks, search the SYMBOL vocabulary too — a novel name on a stock-symbol cliché still invites confusion claims from similar combinations
**Geographic caution:** Common words clear in one market can be famous marks in another; ask where the client sells
**Escalate, don't conclude:** A knockout pass improves odds; only counsel clears
**Best For:** SSB warnings; Presentation Q&A preparation

## RS-LIC-TM-004 — Red Flags in the Design Room

**Definition:** Early-warning signs that a direction is legally fragile
**The client's favourite existing logo:** "make it like X" — imitation invites confusion refusal and takedown
**Category clichés as the only device:** The stock-symbol list (scales, dumbbell, steaming cup) is dense with prior registrations — clichés are not just weak design, they're crowded ground
**Descriptive wording as the hero:** Taglines describing quality ("Simply Better") carry no exclusivity
**Surname as mark:** Surnames can be refused or weakly protected unless they acquire distinctiveness
**Geographic names:** Place names for goods from elsewhere mislead
**Colour-alone claims:** Colour as the ONLY distinguishing feature is weak protection; form must carry the identity (ties to PRD-004's one-colour test)
**Best For:** Judge originality dimension; Insight cliché flags gaining legal weight

## Trademark Check Framework

| Checkpoint | The question | Weak sign |
|-------------------|--------------|-----------|
| Spectrum position | Where does the mark sit: generic → fanciful? | Descriptive or generic |
| Combination test | Do symbol + wordmark TOGETHER clear the bar, even if parts don't? | Neither part contributes |
| Knockout pass | Exact + near names and visual neighbours searched in class? | Unexamined lookalike in class |
| Cliché ground | Is the core device on the crowded-symbol list? | Stock symbol as the only device |
| Deception scan | Does anything promise what the business isn't? | Geographic or quality misdescription |
| Colour dependence | Does identity survive monochrome? | Colour is the only differentiator |
